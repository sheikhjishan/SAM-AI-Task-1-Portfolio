# Jishan Akhatar - Personal Portfolio

A modern and responsive personal portfolio website developed as part of my Web Development Internship at SAM AI Technologies.

## 🚀 About the Project

This portfolio website showcases my profile, technical skills, projects, resume, and contact information.

The project is built using HTML, CSS, and JavaScript with a responsive design for desktop, tablet, and mobile devices.

## ✨ Features

- Responsive personal portfolio
- Hero / introduction section
- About section
- Technical skills section
- Projects showcase
- Resume download
- Contact information
- GitHub links
- Responsive navigation
- Smooth scrolling
- Scroll reveal animations
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
